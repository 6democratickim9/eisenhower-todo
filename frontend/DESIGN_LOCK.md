# DESIGN LOCK

이 파일은 기능 구현 중 시각적 재디자인을 방지하기 위한 기준입니다.

## 고정 토큰
- Deep Forest: `#173F35`
- Rich Green: `#215B49`
- Warm canvas: `#F3EADC` 계열
- Coral: `#FF766C`
- Mint: `#72C9AF`
- Lavender: `#C6AEFF`
- Butter: `#F6CF57`
- Wasabi: `#E9F056`
- Main panels: white with opacity, not opaque sage

## 고정 구조
1. Deep Forest left sidebar
2. Greeting + search + Add Something topbar
3. Four summary cards
4. Home desktop body: 2×2 Matrix on left + right rail on right
5. Right rail: Daily Check / Today’s Queue / My Jira Watch
6. AP/Daily editors open as right-side overlay drawers and do not compress the Matrix

## 금지
- 전체 workspace를 sage/khaki/brown solid fill로 변경
- sidebar 구조를 top navigation으로 변경
- Matrix를 list/table 형태로 대체
- Q1~Q4 색상 역할 교체
- team avatars / assignee-centric collaboration UI 추가
- 기능 구현을 이유로 card radius, density, major spacing hierarchy를 임의 재설계
