# UI Update — 2026-09-04

- Right rail: persistent **Note** card added below Jira Watch.
  - Saves to the same local planner JSON through `PUT /api/note`.
  - Auto-saves on blur; Ctrl/Cmd + Enter also saves.
  - 12,000 character limit.
- Matrix Q4 renamed from **DON’T DO** to **BACKLOG**.
- Decorative gradients removed from the main canvas, sidebar, add menu, summary cards, and quadrant surfaces.
- Quadrants now use flat pastel fills with subtle solid decorative shapes.
- Assignee/avatar UI was intentionally not added.

## Hotfix: Note save 405
- Rebuilt the bundled Windows Go backend from the current source so `PUT /api/note` is present.
- Added an HTTP regression test for the note route.
- Separate-backend launcher now uses strict port 8787 instead of silently falling back, preventing Vite from continuing to talk to an older process on 8787.
- Frontend now reports a clear stale-backend error if it receives HTTP 405 from the note endpoint.
